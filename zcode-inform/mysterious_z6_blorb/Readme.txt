This zip folder contains Graphical Z-Code versions of the Mysterious Adventure series,
previous only available in Z-Code without pictures.


Mysterious Adventures (c) 1981,82,83. 
All games written by Brian Howarth. 
#05, #06 and #07 co-written by Wherner Barnes, 
#8 and #11 co-written by Cliff J. Ogden.

Z-Code Graphic Versions Of Mysterious Adventures
------------------------------------------------
Game files were converted to Z-Code by Colin Davies with the assistance of scott2zip (by Bjorn Gustavsson).
Pictures were obtained from the ZX Spectrum releases.

To play these games you require a Z-Code interpreter which can play z6 files, such as WinFrotz.
Handheld/Pocket PC's may not be able to display the pictures properly due to limited screen size.
